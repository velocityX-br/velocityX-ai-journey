06 / RRF 算法
Reciprocal Rank Fusion Formula
score(d) = Σ    1 k + ranki   where  k = 60
文档 docs 排名 code 排名 RRF 得分 最终排名
文档 A #1 #4 1/61 + 1/64 = 0.0320 #1 (tie)
文档 C #5 #1 1/65 + 1/61 = 0.0320 #2 (tie)
文档 B #3 — 1/63 = 0.0159 #3
Insight 01
k=60：BEIR 基准实验中的
黄金超参数常数
Insight 02
解决跨集合分数不可比问题——
向量分数无法直接混合
Insight 03
纯排名融合，无需标定，
不依赖分数绝对值
